# KYC Autofill Workbench

A local-first MVP for reviewing AI-assisted Know Your Customer (KYC) document extraction. Built with React, TypeScript, Tailwind, and Shadcn-inspired components.

## Features
- Upload PDFs or images via drag-and-drop
- Manage cases for individual or corporate clients
- Store your OpenAI API key locally and trigger GPT-4o extraction
- Split-pane workspace with document preview and editable structured form
- Export reviewed data as JSON

## Getting Started
1. Install dependencies
   ```bash
   npm install
   ```
2. Run the development server
   ```bash
   npm run dev
   ```
3. Open the app and add your OpenAI API key in the header settings before analyzing documents.
